# Components reference

ScholarMate AI is plain HTML/CSS/JS (no framework), so "components" are
implemented as **CSS class contracts + small JS render functions**, not
importable files. This keeps every page a plain `.html` file that works
by just opening it in a browser, while still keeping markup reusable and
consistent. This folder documents each component: what it looks like,
which CSS classes back it, and which JS file (if any) generates it.

| Component | CSS classes | Generated by |
|---|---|---|
| Navbar | `.navbar`, `.nav-links`, `.nav-mobile` | `Navbar()` in `js/main.js` — see `navbar.html` in this folder |
| Footer | `.footer` | `Footer()` in `js/main.js` — see `footer.html` in this folder |
| Buttons | `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-ghost`, `.btn-sm`, `.btn-icon`, `.btn-block` | static markup, ripple wired in `js/main.js` |
| Feature card | `.card.feature-card` | static markup on `index.html` / `about.html` |
| Scholarship card | `.card.scholarship-card` | `scholarshipCardHTML()` in `js/results.js` |
| Chat bubble | `.chat-bubble-row`, `.chat-bubble` | `appendMessage()` in `js/assistant.js` |
| Loading spinner | `.spinner` (add `.dark` on light backgrounds) | static markup, used in `js/finder.js` |
| Loading skeleton | `.skeleton`, `.skeleton-card`, `.skeleton-line` | `renderSkeletons()` in `js/results.js` |
| Toast notification | `.toast-stack`, `.toast` | `showToast()` in `js/main.js` — call `showToast("message")` from anywhere |
| Empty state | `.empty-state` | static markup on `results.html`, `details.js` |
| Form field | `.field`, `.input`, `.select`, `.toggle-chip` | static markup on `finder.html`, `contact.html` |

## Example: scholarship card

```html
<article class="card card-lift scholarship-card fade-up">
  <div class="scholarship-card__top">
    <div>
      <div class="scholarship-card__name">Scholarship name</div>
      <div class="scholarship-card__meta">Provider · State</div>
    </div>
    <div class="match-badge">96%<span>MATCH</span></div>
  </div>
  <p class="scholarship-card__desc">Short description…</p>
  <div class="scholarship-card__facts">
    <span class="fact-chip is-amount">₹75,000</span>
    <span class="fact-chip is-deadline">Due 30 Nov 2026</span>
  </div>
  <div class="scholarship-card__actions">
    <a href="details.html?id=sch_001" class="btn btn-secondary btn-sm">View Details</a>
    <a href="https://www.education.gov.in/scholarships" target="_blank" rel="noopener noreferrer" class="btn btn-ghost btn-sm">Official Website</a>
    <a href="https://scholarships.gov.in/" target="_blank" rel="noopener noreferrer" class="btn btn-primary btn-sm">Apply Now</a>
  </div>
</article>
```
